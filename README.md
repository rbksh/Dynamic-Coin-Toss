# Dynamic Coin Toss - Independent Research Project - Shesh Shiromani

This is an independent research project that investigates the deterministic physical dynamics of a coin toss and its intersection with human cognitive bias. Built entirely in Python, the project explores how Chaos Theory acts as the mathematical translator between the absolute determinism of physical laws and the statistical illusions categorized by the Law of Small Numbers.

**Core Research Focus**

* **Parametric Analysis:** Analyzing the specific physical parameters that govern a coin in flight, including initial upward velocity, angular momentum, moment of inertia, and aerodynamic friction. The core premise is that a coin toss is not a random 50/50 statistical event, but a highly sensitive mechanical system dictated entirely by its initial conditions.
* **The Law of Small Numbers:** Examining the psychological phenomenon where human observers incorrectly assume that a small sequence of events will reflect the theoretical probability distribution over a large parent dataset as well. This covers the cognitive friction that occurs when natural clusters or streaks appear, which the human brain rejects as "non-random."
* **Chaos Theory:** Demonstrating how deterministic physical systems with extreme sensitivity to initial conditions produce data that humans perceive as pure statistical randomness. Chaos theory is positioned as the boundary layer explaining why physical predictability breaks down into psychological and statistical uncertainty, ie, the connecting bridge between parametric analysis and the law of small numbers. 

**System Architecture**

The computational phase of this research uses machine learning to attempt pattern recognition within large chaotic datasets, visualizing the friction between underlying determinism and predictive error over time.

* **Main Simulation Engine (`try_chaos_theory.py`):** Utilizes TensorFlow and Long Short-Term Memory (LSTM) neural networks to analyze and forecast numeric sequences generated by the logistic map equation from chaos theory, mimicking the degradation of predictability in sensitive physical systems.
* **Live Error Analysis:** Deploys a multi-window Matplotlib architecture to track the exact mathematical divergence between the machine learning model's predictions and the actual chaotic state.
* **Real-Time Visualization:** Renders concurrent graphical readouts of raw error direction, absolute mistake magnitude, and interval-to-interval percentage shifts to quantify exactly how rapidly a chaotic system evades prediction.

**Installation and Execution**

The execution environment requires specific libraries to run the simulation and render the simultaneous data visualizations.

**Dependencies**
* `numpy>=1.26.0`
* `matplotlib>=3.8.0`
* `tensorflow>=2.16.1`

**Execution Steps**
1. Navigate to the local project directory.
2. Install the required dependencies: `pip install -r requirements.txt`
3. Execute the main simulation engine: `python try_chaos_theory.py`
4. The system will compile the model, train the neural network on the chaotic sequence, and simultaneously launch four synchronized visualization windows detailing the predictive breakdown.
